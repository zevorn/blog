Just-in-time compilation (JIT, short for Just-In-Time Compilation) is a dynamic compilation technique that converts source code or an intermediate representation (such as bytecode) into machine code during program execution. Unlike traditional static compilation, a JIT compiler selectively compiles code fragments at runtime and can optimize them according to the current execution context.

Below we use Rust to build a minimal JIT example, based on [rustyjit][1].

## Basic Idea

1. During process execution, mmap a block of memory called code_buffer (4 KiB aligned) and set its permissions to readable, writable, and executable;
2. Emit the binary encoding of a host instruction sequence into code_buffer;
3. Cast the entry address of the program section in code_buffer to a function pointer;
4. Execute that function pointer.

## Prerequisites

### FFI Programming

Allocating memory in a process requires calling libc interfaces, which involves [Rust FFI Programming - libc crate][2]. In short, we need to `extern` the libc crate already wrapped by Rust so that we can access the interfaces we need. The main ones are:

1. mmap()
2. memset()
3. mprotect()
4. memalign()

Note that some interfaces in Rust are already wrapped variants, usually associated functions, and cannot be used with the raw API names.

### Trait

A trait can tell the compiler what characteristics a particular type has and what it can share with other types. We can use traits to define this shared behavior in an abstract way, and we can also use trait bounds to require that a generic type implement some specific behavior.

Because Rust is a very safety-oriented language, we need to rely on traits to implement mutable access to memory.


## Building a Minimal JIT

First define a struct that contains a pointer to code_buffer:

```bash
struct JitMemory {
    code_buffer: *mut u8,
}
```

Then we write a `new` method to allocate and initialize memory:

```rust
std::mem;
// Define the page-size constant
const PAGE_SIZE: usize = 4096;

impl JitMemory {
    fn new(num_pages: usize) -> JitMemory {
        let code_buffer: *mut u8;
        unsafe {
            let size: usize = num_pages * PAGE_SIZE;
            let mut _contents: *mut libc::c_void =
            mem::MaybeUninit::<libc::c_void>::uninit().as_mut_ptr();
            // Allocate memory and align it to the page size
            libc::posix_memalign(&mut _contents, PAGE_SIZE, size);
            // Set memory permissions to executable, readable, and writable
            libc::mprotect(
                _contents,
                size,
                libc::PROT_EXEC | libc::PROT_READ | libc::PROT_WRITE,
            );

            // Initialize memory contents to the 'RET' instruction
            libc::memset(_contents, 0xc3, size);
            code_buffer = mem::transmute(_contents);
        }

        JitMemory { code_buffer }
    }
}
```

Next we implement bytecode emission for instruction encodings:

```rust
use std::ops::{Index, IndexMut};

// Implement the Index trait to allow indexed access to memory
impl Index<usize> for JitMemory {
    type Output = u8; // Declares the associated Output type for Index<usize> as u8

    fn index(&self, _index: usize) -> &u8 {
        unsafe { &*self.code_buffer.offset(_index as isize) }
    }
}

// Implement the IndexMut trait to allow indexed mutation of memory
impl IndexMut<usize> for JitMemory {
    fn index_mut(&mut self, _index: usize) -> &mut u8 {
        unsafe { &mut *self.code_buffer.offset(_index as isize) }
    }
}
```

Finally, we write a simple assembly program, emit it into memory, and run it:

```rust
fn run_jit() -> fn() -> i64 {
    let mut jit: JitMemory = JitMemory::new(1);

    // Write machine code in JIT memory to generate a function that returns 3
    jit[0] = 0x48; // mov RAX, 0x30
    jit[1] = 0xc7;
    jit[2] = 0xc0;
    jit[3] = 0x30;
    jit[4] = 0;
    jit[5] = 0;
    jit[6] = 0;

    // Convert the memory pointer into a function pointer and return it
    unsafe { mem::transmute(jit.code_buffer) }
}

fn main() {
    // Generate and call the JIT-compiled function, then print the result
    let fun: fn() -> i64 = run_jit();
    println!("{:#x}", fun());
}
```

Compile and run it to see the output:

```bash
$ cargo run
...
0x30
```
